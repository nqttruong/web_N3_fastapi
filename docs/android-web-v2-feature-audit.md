## Quy tắc triển khai V2

- Nội dung static Android → Web đi qua scanner read-only; Web study progress dùng bảng riêng, không ghi vào Android `learning_progress` hoặc `WordsReciteRecord`.
- Luyện flashcard theo bài chỉ ghi kết quả phiên; chỉ luồng Ôn bài tạo lịch SRS. Đây là phân biệt quan trọng trong Android source.
- Nguồn chưa xác minh quyền chỉ được nhập sau khai báo riêng `pack_id/source_id`, rights holder, basis, usage, scope private. Sở hữu bản sao cá nhân không tự cấp quyền phát hành công khai.
- Mọi số đếm học là dữ liệu PostgreSQL Web; chưa thể diễn giải là tiến độ học trên điện thoại.
- Chỉ có Web mirrors và JLPT review events tương thích protocol Android hiện tại; chưa kiểm thử thiết bị với endpoint HTTPS thật.
